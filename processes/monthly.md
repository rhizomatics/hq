# Monthly

## 1st — Alignment review — `/alignment-review`
- **Who:** architect
- **Output:** `hq-private/reports/alignment/YYYY-MM.md`
- Improvements in one repo's tooling config, docs plugins or templates to spread to others.

## 4th — Support review — `/support-review`
- **Who:** pm
- **Output:** `hq-private/reports/support-review/YYYY-MM.md`
- Recurring support themes and root-cause fixes in code, tests or docs.

## 10th — Ecosystem review — `/ecosystem-review`
- **Who:** architect
- **Output:** `hq-private/reports/ecosystem/YYYY-MM.md`
- Home Assistant and SignalK releases and upcoming changes: threats and opportunities. The 10th is always after HA's release on the first Wednesday of the month.
- Other dependencies that are worth upgrading for feature, performance or security reasons and safe to do so

## 11th — GitHub review — `/github-review`
- **Who:** infra-lead
- **Output:** `hq-private/reports/github/YYYY-MM.md`
- Workflow consistency per app type, settings drift, new GitHub features, root causes of
  recurring build failures.

## 18th — Agent accessibility — `/agent-accessibility-review`
- **Who:** architect
- **Output:** `hq-private/reports/agent-accessibility/YYYY-MM.md`

## 24th — Reputation review — `/reputation-review`
- **Who:** marketing
- **Output:** `hq-private/reports/reputation/YYYY-MM.md`
- Mentions and sentiment trends, search visibility, listings, competitors. Ends with manual checks.

## Last Friday — Project review (monthly) — `/project-review`
- **Who:** pm
- **Output:** `hq-private/reports/projects/YYYY-MM-DD.md`
- The weekly review plus refining each project: goal, scope, shape, whether it's still worth doing.
