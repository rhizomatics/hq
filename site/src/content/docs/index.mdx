## How this works

Each recurring process is a Claude Code skill run by a persona (pm, architect, infra-lead,
marketing, tech-writer). Anything that needs the maintainer becomes an issue in a private
companion repo; changes arrive as pull requests. Raw metrics, security findings and support
triage stay private. This site is rebuilt daily from the public
[hq repo](https://github.com/rhizomatics/hq) and the public aggregates of the private data.
