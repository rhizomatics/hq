# Daily decision follow-up

The maintainer answers hq issues by commenting on them. This skill finds those answers and acts
on them. Silence is the expected outcome: most days there is nothing new.

## Find new decisions

1. List open issues in `rhizomatics/hq-private` assigned to `jeyrb`:
   `gh api "repos/rhizomatics/hq-private/issues?state=open&assignee=jeyrb&per_page=100"`.
2. For each one, read the comments (`gh api repos/rhizomatics/hq-private/issues/<n>/comments`).
   A comment needs acting on when it was written by `jeyrb`, and no comment by an agent after it
   says `<!-- hq:followup -->`. Agents post as `jeyrb` too, so tell them apart by that marker
   and by the `_Generated by Claude Code_` footer: a `jeyrb` comment without the footer is the
   maintainer's.
3. Also act on checklist items the maintainer has ticked or edited in the body when the issue
   says ticking is the approval.

## Act

For each decision, in the persona that owns the issue's label (see `team.md`):

- **Approval or clear choice:** carry it out within the rules in `CLAUDE.md`. Changes to product
  repos are PRs, one repo and one theme each, review requested from `jeyrb`. Where an open agent
  PR already covers that theme in that repo, push to its branch instead of opening a new one.
  Policy wording the decision settles goes into `policies/` in `hq` in the same run.
- **Unclear or conflicting answer:** don't guess. Post a short question with
  `<!-- hq:needs-action -->` so it pings.
- **Too big for one run:** do what fits, list the rest in the follow-up comment, and leave those
  items unticked.

Then post one follow-up comment per issue. It starts with `<!-- hq:followup -->`, lists what was
done (PR links, commits) and what's left, and ticks the items now done in the body. Add
`<!-- hq:needs-action -->` only if it asks for something new. Close the issue when every item is
done or handed to a PR the maintainer only has to merge.

## Output

`hq-private/reports/decisions/YYYY-MM-DD.md`, only on days something was picked up: one line per
issue with what was done and the links. No file on quiet days.
