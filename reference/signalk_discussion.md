# SignalK discussion sites

Watched by `/forum-watch` on each source's cadence: daily | weekly (Mondays) | fortnightly (Mondays of
even ISO weeks) | monthly (1st). `How to search` tells the agent which access method works.

| Community | URL | Cadence | How to search |
|---|---|---|---|
| SignalK server discussions | https://github.com/SignalK/signalk/discussions | daily | read `SignalK/signalk` discussions through WebFetch since GraphQL not available in cloud env |
| Panbo forum: Network your boat | https://panbo.com/marineelectronicsforum/network-your-boat/ | fortnightly | wpForo RSS: `<url>?type=rss2&forum=network-your-boat` (recent topics); search: `https://panbo.com/marineelectronicsforum/?wpfs=<terms>&wpfin=entire-posts&wpfob=date` |
