even ISO weeks) | monthly (1st). `How to search` tells the agent which access method works.

| Community | URL | Cadence | How to search |
|---|---|---|---|
| SignalK server discussions | https://github.com/SignalK/signalk/discussions | daily | read `SignalK/signalk` discussions through WebFetch since GraphQL not available in cloud env |
