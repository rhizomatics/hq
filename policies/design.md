# Design

The design artefacts will be reviewed during the regular scheduled design review.

## RFC Process

Major changes, such as new features and extensive refactoring, will be planned using Request for Comment (RFC) documents, stored in the `docs/developer/design` directory so they are publically available.

RFCs *may* be accompanied by a GitHub discussion, where there's a likelihood of someone noticing and contributing.

## Design Principles

A `design_principles.md` in `docs/developer/design` will be used for larger projects to state the overall principles, including scope, such as where something is expected in HomeAssistant/SignalK/some other plugin vs this one.

## Road Map

A `roadmap.md` in `docs/developer/design` will be used to summarize anticipated major projecta (which may not have an RFC yet) as well as smaller changes. It will be used rather than necessarily adding GitHub feature Issues every time.
