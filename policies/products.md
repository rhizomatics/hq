# Products

Products will follow all the other HQ policies except where an exception listed.

## Git Repositories

Each product will have be listed in HQ at `repos.toml`
Products with an 'experimental' status won't be shown on the public index, all others will be show in public HQ and listed under appropriate category at https://www.rhizomatics.org.uk (the `.github` project).

## GitHub

- Product repos will all have Actions, Issues, Pull Requests and Discussions enabled
  - Wiki and Projects will be disabled
- All available, free of charge, code quality and security tooling will be enabled
- Social Preview will be enabled for all products, using Rhizomatics branding customized for the product

## Documentation

README.md will have a 'Managed by HQ' badge with link back to https://hq.rhizomatics.org.uk
