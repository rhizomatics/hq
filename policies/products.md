# Products

Products will follow all the other HQ policies except where an exception listed.

## Git Repositories

Each product will be listed in HQ in `repos.toml`.
Products marked `category = ["experimental"]` there aren't shown publicly. All others are shown on the public HQ site and listed under the appropriate category at https://www.rhizomatics.org.uk (the `.github` project).

## GitHub

- Product repos will all have Actions, Issues, Pull Requests and Discussions enabled
  - Wiki and Projects will be disabled
- All available, free of charge, code quality and security tooling will be enabled
- Social Preview will be enabled for all products, using Rhizomatics branding customized for the product

## Documentation

README.md will have the 'managed by hq' badge linking back to https://hq.rhizomatics.org.uk (exact markdown in `project_standards.md`).
